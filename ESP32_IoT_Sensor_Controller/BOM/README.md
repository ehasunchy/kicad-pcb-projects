# Bill of Materials (BOM)

This folder contains the Bill of Materials for the ESP32 IoT Sensor Controller PCB project.

## Files
- `ESP32_IoT_Sensor_Controller_BOM.xlsx` — Editable Excel BOM with CSV data connection.
- `ESP32_IoT_Sensor_Controller_BOM.pdf` — Formatted BOM for documentation and review.

## BOM Information
- **Design Tool:** KiCad 10
- **PCB:** 2-layer
- **Component Quantity:** 36
- **Component Groups:** 21
- **Fields:** Reference, Quantity, Value, Footprint, Datasheet, Manufacturer, and Manufacturer Part Number (MPN).

## Project Status
Designed for educational and portfolio purposes. PCB manufacturing and physical testing have not yet been completed.
